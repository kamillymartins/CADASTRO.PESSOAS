# 👥 Sistema de Cadastro de Pessoas

## 📖 Sobre o Projeto

Este projeto foi desenvolvido em Python com o objetivo de realizar o cadastro simples de pessoas por meio de um menu interativo no terminal.

O sistema permite cadastrar usuários informando nome, telefone e e-mail, oferecendo uma interface simples para praticar conceitos fundamentais de programação.

---

## 🚀 Funcionalidades

* Menu interativo;
* Cadastro de usuários;
* Armazenamento de informações básicas:

  * Nome;
  * Telefone;
  * E-mail;
* Opção para listar usuários cadastrados;
* Opção para encerrar o programa.

---

## 🛠️ Tecnologias Utilizadas

* Python 3
